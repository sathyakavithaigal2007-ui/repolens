            How the score works

            Each check gives 0 to 100. The overall score is the weighted average. These are heuristics from file names, sizes and commit counts, so treat them as a fast first read, not a code review. Lines of code are estimated from file sizes.

            CheckWeightWhat it looks at
            Structure20%Files in the repository root, number of folders, nesting depth, dependency manifest, .gitignore, and whether one folder holds most of the code.
            Documentation20%README presence and length, LICENSE, a docs folder, CONTRIBUTING and CHANGELOG files.
            Testing25%Test files as a share of source files, plus a CI configuration that can run them.
            Maintainability20%Source files over 30 KB, CI, linter or formatter config, and a committed lock file.
            Activity15%Time since the last push and how many of the last 26 weeks had commits.
            RepoLens runs in your browser and calls GitHub's public API, which allows 60 requests per hour without a token. Source code is never downloaded, only the file tree.
